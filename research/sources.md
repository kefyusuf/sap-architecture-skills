## Important scope qualifiers

- `SAP-004` now uses the matching **on-premise S/4HANA 2025 FPS01** Blocking Invoices source. Exceeding an upper tolerance can **block payment while invoice posting still occurs**; it does not automatically reject all invoice posting.
- `SAP-003` describes an **SAP Retail site/article** process; `SAP-005` describes a **Maintenance Management** process. Treat them as contextual and require MM-focused corroboration before generalizing.
- `SAP-015` supports the GR-based prerequisite directly in its quality-inspection scenario, with `SAP-009` retained only as contextual market-price evidence; invoice-before-GR in `SAP-001` concerns other settings. Do not treat this as an unqualified statement for every product or item type.
- `SAP-012` documents purchase-order item fields, not a guaranteed acceptance outcome for overdeliveries.
- `SAP-008` is from a specialized best-practice process; it illustrates movement code 101 but must not be generalized into all procurement paths.
- Runtime provenance: **none**. ERPNext source analysis: **not yet performed in this M0 package**.
- **v0.4.1 access caveat:** Official SAP Help article text was rechecked through indexed results showing the target edition for key sources, but requests to several exact `?version=2025.001` URLs failed in the browsing environment. Link resolution and version display for each registered URL still require independent reviewer checks; the parameter alone is not proof of an immutable snapshot.

- `SAP-013` supersedes the use of Retail and multiple-account-assignment references as *primary evidence* for partial deliveries in the baseline PO-based invoice process. `SAP-003` and `SAP-010` remain contextual examples, not universal proofs.
- `SAP-014` establishes movement 101 in the MM-IM PO receipt procedure; it does **not** establish that all goods receipts are valuated or that every special stock case works the same way.
- Most SAP Help pages render dynamically in generic HTML fetches. The desk audit used search-indexed official SAP Help excerpts with matching titles/URLs. Stable URL identification is not an archived immutable page snapshot; revisit these before release or on vendor revisions.
